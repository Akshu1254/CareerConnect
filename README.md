# CareerConnect — Job Portal UI

A responsive, front-end job portal concept built with HTML, CSS and vanilla JavaScript.

## Features
- Reference-inspired dark and golden login page with responsive split layout
- Signup and forgot-password form previews with password visibility toggle
- Responsive desktop and mobile layout
- Job cards with category, workplace and keyword filters
- Save/unsave job interaction
- Apply, login, profile and recruiter-posting modal previews
- Search by role, skill, company or location

## Run locally
Open `index.html` in a browser. No build tools are required.

## Deploy on GitHub Pages
1. Create a public repository named `CareerConnect`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then save.

## Important
This is a front-end demonstration. Login, application submission, recruiter posting, and persistent saved jobs require a backend and database. The demo does not collect or transmit personal information.
